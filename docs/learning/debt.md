# Debt Ledger — the single live ledger

Known problems that are NOT fixed. A settled choice goes in decisions.md; a
known-unfixed problem goes here. Don't convert one into the other.

**IDs are permanent and never renumbered**, so an item stays traceable to the
phase that surfaced it. New debt is numbered by the surfacing phase: P1-01, P1-02, …
Constraints are cited by ID (C-xx) from decisions.md.

Not @-imported by CLAUDE.md. Each phase names the IDs it owns in current-phase.md;
/review-as-mentor checks for debt added without an entry here.
